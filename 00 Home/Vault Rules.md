# Vault Rules (how this vault stays editable)

1. **One thing per note.** One car = one note. One part slot = one note. One race type = one note.
2. **Every fact lives in exactly one place.** Other notes *link* to it, never copy it. Change it once, it's changed everywhere.
3. **All numbers live in `09 Rules & Settings`.** Prices, PR points, tier ranges, payouts, timers. Design notes describe *how* things work; settings notes hold *how much*.
4. **Status on every note:** 🟡 Draft → 🟢 Locked. Only Locked notes get built in Roblox.
5. **Decisions get logged** in [[Decisions Log]] with the date, so nobody wonders why something changed.
6. **Unanswered stuff goes in [[Open Questions]]**, not guessed.
7. The folder structure mirrors the future Roblox code: each section becomes its own module/data file, so editing one never breaks another.
