# Tuning (driving feel)

**Can Roblox do this? Yes.** Roblox car chassis (custom ones or the popular community A-Chassis) expose these settings in code:

| Tuning option | Doable? | Notes |
|---|---|---|
| Gear ratios (speed vs accel) | ✅ Easy | Just numbers in the transmission config |
| Ride height | ✅ Easy | Suspension length |
| Camber | ✅ Easy (mostly visual) | Wheel angle |
| Suspension stiffness | ✅ Easy | Spring/damper values |
| Grip ↔ drift slider | ✅ Doable, needs testing | Changes rear tire grip + steering; tied to the drift tech test |
