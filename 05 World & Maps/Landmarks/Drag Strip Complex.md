# Drag Strip Complex

Inspired by real drag strips (Texas Motorplex style). No real sponsor logos; banners are placeholder colors.
Built in Studio under `OverTake_Hub > Drag Strip`, woven into the north edge of the city.

## What's built
| Part | Notes |
|---|---|
| Track | 2 lanes split by a center line, concrete launch pad, asphalt, shutdown area, sand trap, walls with banner panels |
| Christmas tree | Light pole in the middle just past the start line: pre-stage, stage, 3 amber, green, red per lane. Lights are OFF until scripted |
| Tower | 3-story building behind the start line; cars drive through the middle opening from staging |
| Burnout box | Wet-look pad behind the start line |
| Grandstands | Both sides near the start, 8 tiers, roof canopy; south stands open onto a plaza on the city's top street |
| Staging lot | West of the tower, linked to the city street grid |
| Return road | Runs back along the north side from the shutdown turnoff to staging |
| Pits / parking | Lot north of the return road |

## Layout (studs)
- Track centerline Z = -1250; start line X = -900; finish X = 540; shutdown to X = 1140
- N-S main avenue shortened to stop at the city edge (Z -1150)
