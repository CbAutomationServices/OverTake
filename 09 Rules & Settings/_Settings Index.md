# Rules & Settings Index

**Every number in the game lives here.** Design notes link here instead of writing numbers themselves.
When we build in Roblox, each note becomes its own config module, so changing a value never touches game logic.

| Settings note | Holds |
|---|---|
| [[Car Stats]] | Every car's base stats, base PR, max PR, and price. One row per car. |
| [[Part Values]] | Price and PR points for every part slot × level. |
| [[PR Settings]] | Formula constants for the Performance Rating. |
| [[Tier Settings]] | PR range for each tier. |
| [[Race Settings]] | Payouts, entry fees, laps, timers, max players per race type. |
| [[Economy Settings]] | Starting cash, rep per race, level curve. |
| [[Heat Settings]] | Heat levels, cop counts, bust penalties. |
| [[World Settings]] | Day/night length, weather, traffic density. |
| [[Server Settings]] | Max players per server, spawn rules, data saving. |
| [[Game Rules]] | Player rules: collisions, ghosting, AFK, griefing, chat. |
