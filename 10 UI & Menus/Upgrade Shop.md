# Upgrade Shop

## What's on screen (proposed)
- **7 big slot tiles** around the car: Engine, Turbo, Transmission, Suspension, Brakes, Tires, Nitrous. Each shows its current level
- Tap a slot → a level strip (Stock → Elite). Locked levels show "Rep 12" with a lock
- Tap a level → **preview**: ghost bars (green gain / red loss) + a big **+14 PR**. If it would change your tier, the badge flips too (e.g. "C → B")
- One big **BUY** (or **EQUIP** if owned, free) button. Downgrade = equip a lower owned level
- Turbo slot: Turbo vs Supercharger tabs, each with a sound preview
